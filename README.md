# 區塊鏈能源稽核

本專案包含能源資料上鏈存證的後端服務、驗證前端與智慧合約。

## 專案目錄

| 路徑                                    | 內容                                                                              |
| --------------------------------------- | --------------------------------------------------------------------------------- |
| [`backend/`](backend/)                 | FastAPI 驗證、存證與查詢服務；使用方式見 [後端說明](backend/README.md)             |
| [`frontend/`](frontend/)               | 附錄 C 驗證器與 Vue 前端；使用方式見 [前端說明](frontend/README.md)                |
| [`smart-contracts/`](smart-contracts/) | Solidity 合約與 Hardhat 部署腳本；使用方式見 [合約說明](smart-contracts/README.md) |
